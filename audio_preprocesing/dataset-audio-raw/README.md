# dataset-audio-raw (privado)
Origen: Google Drive (enlace interno o carpeta)
Formato: WAV/FLAC/MP3; mono; 16 kHz o 48 kHz
Política de nombres: data/raw/YYYY/MM/DD/<sha256>__orig.ext
Duplicados: se detectan por sha256; no se suben repetidos
Splits: lists en /splits (no mover audios)
Cambios: ver sección Changelog
